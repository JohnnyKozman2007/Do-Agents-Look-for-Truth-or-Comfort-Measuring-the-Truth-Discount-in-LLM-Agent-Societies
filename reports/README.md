# Unified Reports Folder (`reports/`)

All generated empirical reports (Gemini 3.7 Flash judge; Qwen3-32B excluded; Two-Source Probes 1 & 2 not run) live in this folder, while all analysis code lives in `result_analysis/`.

## Contents
1. **`reports/rumor_towns/`** (`report.html`, `report.md`, `csv/`) — Report 1: False Claims (6 main knobs + 4 interactions, 16-DNA combos, Gatekeeper link, Top/Bottom 10 DNAs across all labels & POVs).
2. **`reports/truth_towns/`** (`report.html`, `report.md`, `csv/`) — Report 2: True Claims (identical structure for true claims).
3. **`reports/truth_discount_comparison/`** (`report.html`, `report.md`, `csv/`) — Report 3: Truth Discount (`Truth − Rumor`) & Symmetry Tests (Butterfly & Forest SVG plots, 10-contrast symmetry tests, Model comparison, Top/Bottom TD DNAs).
4. **`reports/roshan_tiers_1_to_4/result_analysis_report_gemini.html`** — Roshan's Tiers 1–4 HTML report generated by `result_analysis/` on the Gemini 3.7 Flash labels (includes judge `CHECKED` recall/precision, Placebo permutation leakage test, Checkers vs. Non-Checkers, Variance decomposition, Scoring sensitivity, and Metrics 4–20).
